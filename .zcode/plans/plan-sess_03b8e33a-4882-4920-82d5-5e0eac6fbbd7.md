# Flip transition (3D card mode)

## Goal
Add a new **Flip** template/mode with:
- Stacked full-stage cards **A** and **B** (not the strip)
- **A** pivots from **center-left edge** (`transform-origin: left center`)
- **B** pivots from **center-right edge** (`transform-origin: right center`)
- Graph lanes for **A rx/ry/rz** and **B rx/ry/rz** (6 independent tracks)
- Existing **Shift left / Bounce out / Zoom up** strip templates unchanged

## Why a second pattern
Current lab is a rigid 4-tile strip with one global pose (`x/y/scale/blur/brightness/opacity`). That cannot express independent A/B 3D origins. Flip needs a branched render + channel model behind `pattern`.

## Architecture

### 1. Pattern discrimination
Extend preset:

```ts
pattern: "mirror-slide-strip" | "card-flip"
```

- `mirror-slide-strip` → current strip DOM + existing channels
- `card-flip` → stacked cards DOM + flip rotation channels (+ shared FX as useful)

Import/export stays v3-compatible; `pattern` selects schema/UI.

### 2. Flip channel model
Add flip-specific tracks (independent of strip tracks):

```ts
type FlipChannelKey =
  | "aRotateX" | "aRotateY" | "aRotateZ"
  | "bRotateX" | "bRotateY" | "bRotateZ";
// degrees
```

Optional shared channels reused from strip pose when helpful:
- `brightness`, `blur`, `opacity`, `scale` (stage FX layer)
- No strip `x` travel in flip mode (cards are full-frame)

Default Flip template (door open):
- A: `rotateY 0 → -90` (hinge left)
- B: `rotateY 90 → 0` (hinge right)
- Other axes 0
- Duration ~700–850ms, mild blur peak
- Perspective ~1200px on stage

### 3. Stage DOM (flip mode only)

```
.transition-lab-stage (perspective: Npx; overflow visible or carefully clipped)
  .transition-lab-fx-layer (shared blur/brightness/opacity/scale, origin center)
    .transition-lab-flip-scene (preserve-3d)
      .transition-lab-card.card-a
        origin: left center
        transform: rotateX() rotateY() rotateZ()
        video A
      .transition-lab-card.card-b
        origin: right center
        transform: rotateX() rotateY() rotateZ()
        video B
```

- Hide strip/mirrors while `pattern === "card-flip"`
- Keep 2-decoder loading path (A/B videos only; no mirror canvases needed in flip)
- Use `backface-visibility: hidden` so faces disappear past 90°
- Put `perspective` on stage (or scene); avoid filters on the preserve-3d parent if they flatten — keep blur/brightness on fx-layer above/beside carefully, or apply filters on each card face if browsers flatten

CSS additions in `src/styles.css` under transition-lab:
- `.transition-lab-stage.is-flip` → perspective
- `.transition-lab-flip-scene` → preserve-3d, full size
- `.transition-lab-card` → absolute inset 0, will-change transform
- `.card-a` / `.card-b` → respective transform-origin

### 4. Graph UI
When flip pattern active, graph shows **6 lanes**:

| Lane | Color family | Range (default) |
|------|--------------|-----------------|
| A RX | blue | -180…180° |
| A RY | blue darker | -180…180° |
| A RZ | blue light | -180…180° |
| B RX | green | -180…180° |
| B RY | green darker | -180…180° |
| B RZ | green light | -180…180° |

- Same interactions as today: drag handles, double-click add, wheel zoom, Alt-pan, chip isolate/solo
- Strip-only lanes (X/Y strip travel) hidden in flip mode
- Shared Bright/Scale can remain as optional extra lanes or stay in side sliders only (recommend: keep Bright/Scale in graph if already used; Flip default can leave them identity)

Side panel:
- Template dropdown includes **Flip**
- Strip X snap buttons hidden/disabled in flip mode
- Keyframe list shows active rotation channel keys

### 5. Sampling / apply
- `sampleFlipTracks(tracks, t, easing)` → `{ a: Euler, b: Euler }`
- Card style builders:

```ts
cardAStyle = {
  transformOrigin: "left center",
  transform: `rotateX(${ax}deg) rotateY(${ay}deg) rotateZ(${az}deg)`,
  backfaceVisibility: "hidden",
}
cardBStyle = {
  transformOrigin: "right center",
  transform: `rotateX(${bx}deg) rotateY(${by}deg) rotateZ(${bz}deg)`,
  backfaceVisibility: "hidden",
}
```

- Compose shared FX via existing `fxLayerStyle` for blur/brightness/opacity/scale when those channels exist

### 6. Template
`buildFlipPreset()` + template entry:

```ts
{ id: "flip", label: "Flip", preset: buildFlipPreset() }
```

Seed curves:
- A RY: `(0,0) → (1,-90)`
- B RY: `(0,90) → (1,0)`
- all other rotates flat 0
- easing: reuse lab default or a slightly snappier out-curve

### 7. Compatibility
- `clonePreset` / `parsePreset` / `buildPreset` branch on `pattern`
- Old presets without flip channels still load as strip
- Export flip presets with `pattern: "card-flip"` and `channels` including rotate keys (and any shared FX keys)
- Do not mutate shift-left / bounceout / zoomup builders

## Files
- `src/VideoTransitionPlayground.tsx` — pattern, channels, sampling, stage branch, graph lanes, Flip template
- `src/styles.css` — flip scene/card styles, stage perspective modifier

## Implementation order
1. Types + parse/clone/export for `card-flip` + rotate channels
2. Flip sampling + card style helpers
3. Stage render branch + CSS
4. Graph lane set switch (6 rotate lanes) + isolate
5. `buildFlipPreset` + template dropdown
6. Hide strip-only controls in flip mode
7. `npm run build`

## Risks / notes
- **Overflow clipping:** stage `overflow: hidden` may clip 3D edges; use modest perspective and/or allow overflow during flip
- **Filter + preserve-3d:** some browsers flatten; if blur looks wrong, move blur to card faces
- **Z-fighting:** at start B is edge-on (`rotateY: 90`); ensure A is above until mid, or slight translateZ separation
- Keep strip templates fully isolated so bounce/zoom/shift stay bit-identical
