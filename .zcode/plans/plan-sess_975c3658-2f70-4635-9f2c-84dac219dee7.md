## Goal

Add a `/button-test` playground page and an editable **CtaButton** with:

1. **Parent** — outer shell, `clip-path: shape(...)`, border/stroke color fill  
2. **Light streak** — sits under the inner layer so it only peeks through the 2px ring (border highlight)  
3. **Inner** — inset by stroke width (default `2px`), same soft-rounded shape, **Aurora** as background + label on top  

Debug panel = **full CTA playground** (size, shape, stroke, streak, Aurora, label, pseudo-states).

---

## Architecture

```
ButtonTestPage (/button-test)
├── preview stage (centered live button)
└── debug panel (sliders / colors / toggles)
      └── drives props on <CtaButton />

CtaButton
├── .cta-button              // parent: shape() clip, stroke color bg
│   ├── .cta-button__streak  // absolute, under inner (border light)
│   └── .cta-button__inner   // inset Npx, overflow hidden, same shape family
│       ├── <Aurora />       // full bleed background
│       └── .cta-button__label
```

**Stroke trick:** parent is filled with stroke color and clipped. Inner is `inset: strokeWidth` and covers the center. Streak is full-bleed on the parent under the inner layer → only visible in the ring.

**Shape:** CSS [`shape()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/basic-shape/shape) soft rounded rect via `hline`/`vline` + corner `arc`s. Corner radius and size driven by CSS variables so debug sliders update live.

```css
clip-path: shape(
  from var(--cta-r) 0,
  hline to calc(100% - var(--cta-r)),
  arc to 100% var(--cta-r) of var(--cta-r) cw,
  vline to calc(100% - var(--cta-r)),
  arc to calc(100% - var(--cta-r)) 100% of var(--cta-r) cw,
  hline to var(--cta-r),
  arc to 0 calc(100% - var(--cta-r)) of var(--cta-r) cw,
  vline to var(--cta-r),
  arc to var(--cta-r) 0 of var(--cta-r) cw,
  close
);
```

Parent and inner share the same `shape()` (percent-based → scales). Inner is smaller via layout inset, not a second path.

## CtaButton API (initial)

```ts
type CtaButtonProps = {
  label?: string;
  width?: number;
  height?: number;
  cornerRadius?: number;      // soft rounded rect
  strokeWidth?: number;       // default 2
  strokeColor?: string;
  // Light streak
  streakColor?: string;
  streakOpacity?: number;
  streakWidth?: number;       // band thickness
  streakAngle?: number;       // deg
  streakSpeed?: number;       // animation duration scale
  streakEnabled?: boolean;
  // Aurora (inner bg)
  auroraColorStops?: [string, string, string];
  auroraSpeed?: number;
  auroraBlend?: number;
  auroraAmplitude?: number;
  // Chrome
  labelColor?: string;
  fontSize?: number;
  disabled?: boolean;
  pressed?: boolean;          // debug force-press
  className?: string;
  onClick?: () => void;
};
```

Layer DOM (simplified):

```tsx
<button className="cta-button" style={cssVars} type="button">
  <span className="cta-button__streak" aria-hidden />
  <span className="cta-button__inner">
    <Aurora colorStops={...} speed={...} blend={...} amplitude={...} />
    <span className="cta-button__label">{label}</span>
  </span>
</button>
```

Light streak: rotating/translating linear-gradient band (or conic sweep) clipped by parent; `pointer-events: none`.
